# GriefGuide
**Practical Support for Estate Management After Loss** 🫂

A compassionate web application helping people navigate the practical next steps after losing a loved one—from funeral arrangements to estate settlement.

## 🎯 About

Losing someone is overwhelming. GriefGuide helps you organize:
- ✓ Funeral and memorial planning
- ✓ Legal and financial tasks
- ✓ Managing their belongings
- ✓ Selling property (if needed)
- ✓ Important documents and notifications

Take it one step at a time. You don't have to do this alone.

## 🌐 Live Demo
**[Visit GriefGuide →](https://afterwords-support.lovable.app/)**

## ✨ Features

### Task Checklist Manager
- Pre-organized task categories (funeral, legal, estate, property, notifications)
- Add, edit, and track progress on action items
- Set due dates and priority levels
- Supportive messages on task completion

### Financial Tracker
- Log and categorize expenses (funeral, legal fees, moving, property costs)
- Real-time expense summaries
- Export data to CSV

### Document Organizer
- Track important documents and their locations
- Checklist of common documents to locate
- Simple, intuitive organization

## 🛠️ Built With

- **Platform:** Lovable
